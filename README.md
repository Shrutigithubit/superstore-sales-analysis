# Superstore Sales Analysis

## Project Overview
An exploratory data analysis project focused on understanding Superstore sales performance using Python, SQL, and Excel. The goal is to identify sales trends, top-performing categories, customer purchasing patterns, and actionable business insights.

## Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Find the top 10 customers by total sales.
- Compare sales across customer segments and regions.
- Generate insights to support data-driven decisions.

## Tools & Technologies
- **Python:** Pandas, Matplotlib, Seaborn
- **SQL:** MySQL
- **Excel:** Data cleaning, PivotTables, charts, and analysis
- **Jupyter Notebook:** Exploratory data analysis

## Project Workflow
1. Load and explore the Superstore dataset.
2. Clean and prepare the data.
3. Analyze sales using Python.
4. Write SQL queries to aggregate and filter sales data.
5. Visualize patterns and summarize business insights.

## Key Insights
- Technology recorded the highest total sales among the product categories analyzed.
- The top 10 customers were identified based on total sales.
- SQL aggregation and `HAVING` were used to identify customers with total sales greater than 1,000.
